# 广角星野图像对齐：为什么单应变换够用

**语言：** 简体中文 | [English](wide-field-registration.md)

> 结论先行：广角星野能对齐，不是因为它“近似平面”，而是因为**星空在无穷远、帧间相机
> 只转动不平移**。针孔相机对纯旋转的成像映射正好是单应变换
> `H = K R K⁻¹`。广角只是把透视项放大，模型本身仍然是 8 自由度的 `H`，不是
> “平移+旋转”能完全描述的。普通深空默认常用的 4/6 自由度相似/仿射变换，在窄视场
> 足够；广角的边角会留下系统性残差。本仓库用 ORB 粗配准 → 星点质心精修 → RANSAC
> 单应 → 独立质量校验，把这件事做得足够稳。

## 1. 问题：广角 + 旋转，不是“整体平移”

固定三脚架拍星野时，相机没有跟着天空转。对相机来说，星星是**方向**，不是屏幕上的
固定点：

- 星点距离地球极远，可以当作在无穷远；相机的小位移不会造成可分辨的视差。
- 帧与帧之间主要是相机的三维旋转 `R`。
- 广角镜头视场大，画面边缘的星和画面中心附近的光线方向差别很大；同一个相机旋转，
  中心和边角的像素位移并不相同。

如果只用“平移”去对齐，中心可能对上了，边角会拖线；只用“平移+旋转+缩放”（相似变换），
窄视场可能够，广角仍会在四角留下透视残差。

---

## 2. 几何：为什么是单应

设像素坐标为齐次向量 `u = (x, y, 1)`，相机内参矩阵为 `K`：

```text
K = [ f   0   cx ]
    [ 0   f   cy ]
    [ 0   0    1 ]
```

`f` 是焦距（像素单位），`(cx, cy)` 是主点。把像素反投影到归一化相机坐标：

```text
x = K⁻¹ u
```

星空在无穷远，帧间没有平移视差；相机旋转 `R` 后，同一颗星的方向从 `x` 变成 `R x`：

```text
x′ = R x
u′ = K x′ = K R K⁻¹ u
```

因此两帧之间的像素映射是：

```text
u′ = H u,        H = K R K⁻¹
```

`H` 是 3×3 齐次矩阵，尺度任意，真正独立的是 **8 个自由度**。它允许平行线在图像中
收敛，这正是广角透视的特征。相似变换只有 4 个自由度，仿射有 6 个；它们都是 `H` 的
特例（要求 `H` 的最后一行是 `[0, 0, 1]`），因此无法表达“分母随位置变化”的透视项。

### 2.1 为什么广角更明显

以绕垂直光轴的小转动 `Δθ` 为例，视场角为 `θ` 的星点，其像点位移近似为：

```text
Δp ≈ f · [tan(θ + Δθ) - tan(θ)]
   ≈ f · Δθ · (1 + tan²θ) + ...
```

`1 + tan²θ = sec²θ` 随视场角迅速增大。中心附近 `θ≈0`，位移接近 `fΔθ`；广角边角
`θ` 很大，同样的相机转动会产生更大的像素位移。用一个全局平移/旋转去拟合，中心对上
了，边角仍然会偏。

> 注意：这是“绕垂直于光轴的轴转”的直观例子。实际星野的旋转轴可以是天极方向，`H`
> 仍然成立；关键是**纯旋转 + 针孔投影**，不是某一种特定旋转轴。

## 3. 仿射/相似变换在广角上差多少

![仿射与单应](images/affine-vs-homography.png)

*图 2：夸张合成例子中，仿射在第四角留下残差，单应能锁住四角。*

上图是**故意夸张**的合成例子，用来放大差异：

- 左：原始网格和四个角点 A/B/C/D。
- 中：用 3 个角点拟合的 6 自由度仿射变换。三个被拟合的点对上了，第 4 个角点 C 仍
  然偏离；网格线保持平行。
- 右：8 自由度单应变换。四个角点都回到目标位置；网格线可以收敛。

在真实窄视场深空里，这个残差通常小于 1 px，所以 4/6 自由度够用。广角、长曝光或
大旋转时，残差会从边角开始变成可见的拖线。此时继续加“平移/旋转”参数没有用，因为
缺的是**透视自由度**。

## 4. 和普通深空对齐方案的差异

先说明：普通深空软件并不是“不会做单应”。PixInsight StarAlignment 等工具也支持畸变
校正/局部模型；这里比较的是**最常见的默认路径**——窄视场、赤道仪跟踪、相似/仿射
星点对齐。

| 维度 | 普通深空默认路径 | 本方案（广角星野） |
| --- | --- | --- |
| 拍摄 | 赤道仪跟踪，长焦/窄视场 | 固定三脚架或跟踪，广角 |
| 帧间运动 | 星点几乎不动，dither 带来小平移 | 相机纯旋转，广角边角位移不同 |
| 变换模型 | 平移+旋转+缩放（4 DOF），有时仿射（6 DOF） | 单应（8 DOF），`H = K R K⁻¹` |
| 透视项 | 窄视场下可忽略 | 必须保留，否则边角拖线 |
| 特征 | 星点图案/星表/plate solve 常见 | ORB 多尺度特征 + 星点质心 |
| 镜头畸变 | 窄视场影响小；部分软件做畸变校正 | 单应不含畸变；用残差校验，必要时预校正 |
| 前景 | 通常无地景，或直接整幅对齐 | 地景掩膜，只对天空配准 |
| 坏帧处理 | 星点数/残差阈值 | 内点数、星点分、残差比例、尺度/平移门限 |
| 叠加 | sigma clipping、drizzle 等 | mean 或 median，memmap 分块 |

### 4.1 模型阶数

| 模型 | 自由度 | 能表达 | 典型场景 |
| --- | ---: | --- | --- |
| 平移 | 2 | 整体平移 | 极短焦、极小视场、快速预览 |
| 相似（平移+旋转+缩放） | 4 | 旋转、缩放、平移 | 普通窄视场深空 |
| 仿射 | 6 | 非均匀缩放、剪切 | 窄视场 + 轻微形变 |
| 单应 | 8 | 透视、平行线收敛 | 广角/透视明显、纯旋转星空 |

本仓库不是先估 `K` 和 `R` 再乘起来，而是直接用 `cv2.findHomography` 拟合 8 自由度
`H`。`K R K⁻¹` 的作用是解释“为什么这个模型物理上是对的”，不是要求相机标定。

### 4.2 特征与鲁棒性

普通深空常用“找星点 → 三角形/四边形匹配 → 相似变换”，因为星点密集、视场窄、初始
旋转小。广角星野的难点是：

- 星点更稀疏、更小，边缘还有彗差/像散；
- 地景纹理容易被误认为星点；
- 初始旋转/透视可能不小；
- 广角镜头畸变会让“全局 H”之后仍有残差。

本仓库的应对是：

1. **半分辨率灰度 + 高通**：压低背景和固定图案，让星点成为局部特征。
2. **ORB 多尺度特征**：对旋转、尺度变化不敏感，先给一个粗 `H`。
3. **地景掩膜**：配准只在天空区域找特征，避免树/建筑边缘污染匹配。
4. **星点质心精修**：ORB 只负责“大致对上”，随后用连通域星点质心做最近邻匹配，
   再用 RANSAC 单应拟合到亚像素。
5. **独立校验**：用高通相关分、星点残差、内点数、尺度/平移门限决定是否接受，而不是
   只看 RANSAC 有没有解。

## 5. 本仓库的实际流程

![配准流程](images/registration-flow.png)

*图 3：ORB 粗配准到星点质心精修的流程。*

代码入口在 `scripts/astro/registration.py`，编排在
`scripts/astro/pipeline.py:34` 的 `_register_task`。

### 5.1 预处理

- 全分辨率 5496×3670 先转成半分辨率灰度 2748×1835；配准只在这个尺度上做。
- 固定三脚架序列：跨帧高分位构建静态模式图（热噪点/固定图案），配准前扣除。
- 跟踪序列：高通相关性高（本轮 0.89），自动跳过静态扣除；否则分位图会把静止星点
  一起删掉。
- 有 `--ground-mask` 时，把天空区域腐蚀成配准掩膜；本轮天空占半分辨率画面 75.0%。

### 5.2 ORB 粗配准

`registration.py:42`：

```python
cv2.ORB_create(nfeatures=12000, scaleFactor=1.2, nlevels=8,
               fastThreshold=5, edgeThreshold=19)
```

匹配用 Hamming 距离 + Lowe 比例测试：

```python
bf = cv2.BFMatcher(cv2.NORM_HAMMING)
knn = bf.knnMatch(mob_desc, ref_desc, k=2)
good = [m for m, n in (p for p in knn if len(p) == 2)
        if m.distance < 0.75 * n.distance]
```

然后用 RANSAC 拟合单应，初始重投影阈值 3 px：

```python
M, inl = cv2.findHomography(src, dst, method=cv2.RANSAC,
                            ransacReprojThreshold=3.0,
                            maxIters=20000, confidence=0.999)
```

这一步给的是“粗变换”：ORB 关键点位置本身有量化误差，广角边角尤其明显，不能直接
拿去叠加。

### 5.3 星点质心精修

`registration.py:88` 的 `refine_transform` 做 4 轮“最近邻 + RANSAC 单应”，容差逐轮
收紧：

```python
for tol in (8.0, 4.0, 2.0, 1.5):
    m2 = cv2.perspectiveTransform(mov_stars, M)
    # 找到 m2 在 ref_stars 中的最近邻
    keep = dist < tol
    Mn, _ = cv2.findHomography(src[keep], dst[keep],
                               cv2.RANSAC, ransacReprojThreshold=tol,
                               maxIters=20000, confidence=0.999)
    if Mn is not None:
        M = Mn
```

注意这里用的也是 `perspectiveTransform` / `findHomography`，不是 `estimateAffinePartial2D`。
星点质心来自高通图的连通域中心，`minarea>=3` 用来排除单像素热噪点。

### 5.4 质量校验

`registration.py:140` 的 `transform_is_plausible` 是最后一道门：

| 条件 | 阈值 | 目的 |
| --- | --- | --- |
| 中心旋转 | `|rot| < 15°` | 排除明显错误/过度旋转 |
| 中心平移 | `< 15%` 画面宽/高 | 排除错配 |
| 局部尺度 | `0.95..1.05` | 帧间不应变焦 |
| 行列式 | `det > 0` | 排除镜像/退化 |
| 内点数 | `>= 25` | 保证有足够星点支撑 |
| 高通相关分 | `>= 0.55` | 变换后星点场真的重合 |
| 星点残差中位数 | `< 3 px` | 亚像素锁定的粗门限 |
| 残差 1.5 px 内比例 | `>= 0.20` | 排除“只有少数星对上” |

校验通过后，半分辨率 `M` 用 `scale_matrix` 换算到全分辨率：

```python
S = np.diag([s, s, 1.0])
M_full = S @ M_half @ np.linalg.inv(S)
```

最后 `warpPerspective` 把全分辨率线性 RGB 帧映射到参考帧。

## 7. 为什么这套方法能把广角对齐

把原因按重要性排一下：

1. **物理模型对**：星星在无穷远，帧间是纯旋转；针孔投影下纯旋转就是单应
   `H = K R K⁻¹`，不是平移/相似变换。
2. **8 自由度足够**：广角的主要问题是透视，不是“星点不够多”。`H` 的透视项能把
   边角的非均匀位移吃掉。
3. **粗到细**：ORB 先给全局初值，星点质心再把边角误差压到亚像素；只靠 ORB 或只靠
   三颗星拟合都不够稳。
4. **地景不参与**：前景在有限距离，存在视差，不能用同一个 `H`；掩膜把它排除，天空
   和地景最后用天地合成拼接。
5. **有独立验收**：RANSAC 有解不等于对；必须同时看内点、星点相关分和残差。坏帧
   宁可不叠，也不让它把星点拖花。
6. **广角仍有足够重叠**：短曝光星野帧间重叠高，ORB 和星点匹配有足够共同星；这是
   特征法能工作的现实条件。

## 8. 边界与局限

单应不是万能的。下面这些情况需要额外处理：

| 情况 | 会发生什么 | 当前处理/建议 |
| --- | --- | --- |
| 强烈桶形/枕形畸变 | 全局 `H` 后仍有径向残差，边角星点拉长 | 先做镜头畸变校正，或扩展为畸变模型/局部 TPS |
| 地景占画面且运动 | 地景违反“无穷远 + 纯旋转”假设 | `--ground-mask` 排除；天地分层合成 |
| 旋转超过 15° | 当前校验会拒绝 | 重新选参考帧、分组配准，或放宽门限并人工检查 |
| 云/星点太稀疏 | ORB/质心匹配失败 | 该帧拒绝；必要时换更长曝光/更高 ISO 重拍 |
| 星点拖线 | ORB 和质心都会偏 | 先排除拖线帧；固定三脚架曝光要短 |
| 大气折射/色散 | 微小色差和位置偏差 | 通常小于像素；极端低空目标需专门建模 |
| 纯平移/脚架移动 | `H` 仍可拟合，但地景/前景视差更明显 | 天地合成；不要让地景参与天空配准 |

尤其注意：**单应描述的是“同一平面/无穷远”的映射**。星空可以近似在一个无穷远平面
上；地景不是。因此广角星野配准的正确对象是天空，地景要单独处理。这也是本仓库把
`--ground-mask` 放在配准和合成链路里的原因。
